## Git workflow and collaboration

Staging selects changes for the next snapshot; committing records that staged snapshot in local history. A branch is a separate line of development, and a pull request proposes changes for review before integration.

| Operation | Purpose |
|---|---|
| `git init` | Start a repository. |
| `git status` | Inspect staged and unstaged changes. |
| `git add` | Stage selected changes. |
| `git commit` | Record staged changes. |
| `git log` | Inspect history. |
| `git branch` | List or create branches. |
| `git switch` | Switch branches. |
| `git push` | Publish commits. |
| `git pull` | Fetch and integrate remote changes. |
